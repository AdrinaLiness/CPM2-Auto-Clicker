# 🏁 CPM2 Auto-Clicker + AI Driver

**Два бота для Car Parking Multiplayer 2 под одной крышей:**

| | Платформа | Как работает |
|---|---|---|
| 🤖 **AI Driver** (новинка) | Android (телефон) | сервис доступности вводит **настоящие касания прямо в игру** — руль, газ, тормоз. Без скриншотов и без ПК |
| 🖥 **Auto-Clicker** | Windows ПК / эмулятор | макросы (запись мыши и клавиатуры) + «Зрение» по шаблонам + AI-водитель по цветовым зонам |

> Идея: ты один раз показываешь, как проехать уровень (или AI пробует типовую траекторию) —
> дальше он проходит его сам. Хоть по кругу.

## 📱 AI Driver для Android — быстрый старт

1. Скачай **`ANDROID/CPM2-AIDriver-v1.0.apk`** (или из [Releases](../../releases)) и установи.
   Android спросит разрешение «устанавливать из этого источника» — разреши.
2. Открой приложение. Нажми **«СЕРВИС ВЫКЛ»** в шапке → в настройках найди
   **«CPM2 AI Driver — ввод касаний»** → включи. Вернись в приложение.
3. Жми **«ОТКРЫТЬ ИГРУ»** — приложение найдёт CPM2 и запустит её.
4. Первый проход — **обучение показом**: вкладка «Уровни» → выбери номер →
   **«Записать заново»** → проедь уровень своими руками → кнопка «Остановить запись».
5. Дальше жми **«СТАРТ»** — AI повторит твою езду в точности до миллисекунд.
6. Проходится? Жми **✓** на плавающей панели — победа сохранится в прогрессе уровня.

Подробная инструкция со скриншотами логики — в `ANDROID/README.txt`.

## 🔍 Как AI залезает в игру без скриншотов

Старые боты (и ПК-часть этого репо) работают «снаружи»: снимок экрана → поиск картинки →
клик. AI Driver работает **изнутри Android**:

- **Ввод** — `dispatchGesture()`: сервис доступности отправляет в систему настоящие
  события касаний. Для игры это неотличимо от твоего пальца: держит газ, крутит руль
  по дуге, тормозит. Одновременно — много-пальцево (газ + руль в одном жесте).
- **Запись** (Android 14+) — `setMotionEventSources()`: сервис слышит **все касания
  экрана**, включая касания в игре, и запоминает их потоком (точка/время/палец).
  Никакой распознавалки картинок — движения самого пальца и есть данные.
- **Повтор** — записанный поток превращается обратно в жесты с точностью ~30 Гц,
  паузы и удержания педалей сохраняются. Повтор не «плывёт», как макрос на ПК.

Ни одного скриншота, ни одного шаблона-картинки. Экран читать не нужно.

## 🎮 Три способа проходить уровни

| Способ | Что нужно | Надёжность |
|---|---|---|
| **Запись → повтор** | Android 14+, проехать уровень 1 раз руками | ★★★★★ точный повтор твоей езды |
| **Манёвр (редактор шагов)** | руки: собрать заезд из шагов «газ 1.5 с + руль влево 70 %» | ★★★★ работает на любом Android |
| **Слепые стратегии AI** | ничего: AI сам пробует типовые траектории | ★★ «попытки» — жми ✓, когда заехал |

Слепые стратегии — это честный «AI пытается пройти каждый уровень»: прямая парковка,
дуга влево/вправо, задним ходом S-манёвром, параллельная. После провала AI берёт
следующую стратегию с другой амплитудой. Как только ты нажал **✓** на плавающей
панели — удачная попытка становится сохранённым решением уровня, и дальше он
проезжается сам одним нажатием.

Прогресс (какой уровень каким способом пройден, сколько побед) хранится в приложении
и виден на вкладке «Уровни»: 💙 запись / 💚 манёвр + счётчик побед.

## 🎯 Калибровка

AI должен знать, где в CPM2 лежат кнопки. Вкладка «Калибровка»: перетащи/тапни точки
ГАЗ, ТОРМОЗ, ВЛЕВО, ВПРАВО, РЕВЕРС, РУЛЬ на мини-схеме экрана (позиции хранятся в
процентах — подходят для любого телефона), затем «СОХРАНИТЬ» и проверь тестовыми
кнопками «Тест: газ 1 с» и т. д. Дефолтные позиции уже близки к стандартной раскладке.

## 🔔 Уведомления и плавающая панель

- **Плавающая панель** висит поверх игры (можно скрыть): ▶ старт · ⏹ стоп ·
  ✓ победа · ✕ провал. Нажимаешь, не выходя из игры.
- **Уведомления** сообщают о ходе заездов: «Уровень 5 ПРОЙДЕН ✓», «попытка не
  удалась — сменю стратегию». На Android 13+ приложение попросит разрешение.

## 📋 Требования

- Android **7.0+** (API 24) — для манёвров, стратегий, оверлея, уведомлений.
- Android **14+** (API 34) — для записи касаний (обучение показом).
- CPM2, установленный на том же телефоне.

## 🖥 Auto-Clicker для ПК

Проверенная версия **2.2** живёт в `PC/`:

- `PC/autoclicker_cpm2.py` — вся программа одним файлом (Python 3.10+);
- `PC/ИНСТРУКЦИЯ.txt` — полная инструкция: установка, макросы, плейлист,
  «Зрение» по шаблонам, AI-водитель по цветовым зонам, автоустановка библиотек.

Работает с окном игры на ПК — и с обычной версией, и с эмуляторами Android
(BlueStacks 5, MSI App Player, GameLoop и т. п.). Быстро:

```
python autoclicker_cpm2.py
```

Библиотеки (pynput, opencv-python, mss, numpy) программа поставит сама при первом
запуске.

## ❓ FAQ

**Это читерство?**
Приложение не трогает память игры, не видит её файлы и не вмешивается в сетевой
код — оно лишь «нажимает кнопки» вместо тебя, как автокликер. Используй по правилам
игры и на свой риск: за прогресс и аккаунт отвечает ты.

**Почему AI не всегда сам проходит уровень?**
Слепым стратегиям не видно экран (так задумано — без скриншотов), поэтому сложные
уровни они проходят не с первой попытки. Самый надёжный путь — обучение показом:
запиши свою езду один раз, дальше AI повторит идеально.

**Работает ли запись на Android 13 и ниже?**
Нет, системная запись касаний появилась в Android 14. На старых версиях доступны
редактор манёвров, стратегии, оверлей и уведомления.

**Эмулятор на ПК?**
Да: включи сервис доступности в настройках Android эмулятора — и приложение будет
управлять игрой прямо внутри него. Но для ПК обычно удобнее бот из `PC/`.
